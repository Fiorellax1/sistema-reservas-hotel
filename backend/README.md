# Backend (fuera del alcance de este Capítulo IV)

El documento del Avance 3 indica expresamente que el backend está **pendiente**.
Esta entrega implementa únicamente el **frontend demostrativo** en HTML, CSS y JavaScript, con datos ficticios guardados en el navegador.
No se incluye Java, Spring Boot, MySQL ni API real.

La implementación posterior de un backend y una base de datos requerirá nuevas pruebas y su propio despliegue.
